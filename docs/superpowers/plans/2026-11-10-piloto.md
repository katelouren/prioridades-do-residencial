# Plano do piloto Prioridades do Residencial

**Objetivo:** demonstrar o fluxo da gestão e do morador com dados compartilhados em uma instalação por residencial.

**Arquitetura:** interface HTML/CSS/JavaScript, API HTTP em Python e SQLite. O servidor valida a consulta e o código de convite antes de registrar o voto.

- [ ] Implementar publicação, convites, votação, encerramento e devolutiva.
- [ ] Implementar telas de acesso, lista, consulta, resultado e gestão.
- [ ] Verificar permissões, voto repetido, resultados e persistência.
- [ ] Documentar instalação e os requisitos para um piloto com moradores.

**Fora deste ciclo:** ocorrências privadas, notificações automáticas, assembleias e uma hospedagem compartilhada entre residenciais.
